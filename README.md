# 🏠 Hostel M8 – Smart Expense Splitter for Hostel Groups

## 📌 About the Project

**Hostel M8** is a smart expense-sharing platform designed specifically for hostel students and roommates. It helps groups manage shared expenses, split bills, track individual contributions, and calculate who owes whom.

Living in a hostel often involves shared expenses such as groceries, food orders, electricity bills, room essentials, and other daily needs. Hostel M8 makes managing these expenses simple, transparent, and hassle-free.

## 🚀 Key Features

- **Group Expense Management:** Create and manage expense groups with roommates.
- **Smart Expense Splitting:** Automatically divide expenses among group members.
- **Expense Tracking:** Keep track of shared spending and individual contributions.
- **Balance Calculation:** Calculate how much each member owes or needs to receive.
- **Settlement Management:** Track payments between roommates.
- **User-Friendly Interface:** Simple and easy-to-use design.
- **Expense History:** View previously recorded group expenses.

## 🎯 Project Objective

The main objective of Hostel M8 is to simplify financial management among hostel roommates by providing a centralized platform for tracking, splitting, and settling shared expenses.
